Neuroanatomy Correlates of Early Biomarkers in Alzheimer's Disease¶

This notebook logistics/gradient-boosted models for predicting conversion from mild cognitive impairment (MCI) to Alzheimer's disease (AD):¶

Model A - demographics + neuroimaging only (baseline)

Model B1 - Model A features + CSF NfL

Model B2 - Model A features + Plasma NfL

Each model is evaluated with cross-validation ROC-AUC using both XGBoost and Logistic Regression in 5 folds and 3 folds, then interpreted with SHAP and Permutation importance.

Data availability: The source data (`mlbaseline_data_v2.csv) is not included in this repository. It contains clinical/biomarker data derived from a restricted-access cohort(data use agreement required). See the README for details on obtaining access.

Five folds cross-validation was intially employed; however, following observation from of the result above and a relatively smaller sample size in both B models, three-fold cross-validation was considered to ensure that each fold retained a sufficient number of observations for model training and validation. Note that this change was not applied on model A as available sample size was considered adequate to support the continued use of five-fold. Regardless three-folds will be applied on Model A in the later stages to note any improvment observed.¶
