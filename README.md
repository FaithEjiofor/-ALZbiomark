# ALZbiomark

**Neuroanatomy Correlates of Early Alzheimer's Biomarker; An open Access Multi-Database Secondary Analysis.**

## Overview
This study aims to systematically map the spatiotemporal relationship between regional nuroanatomical changes and early molecular biomarkers across the preclinical to clinical AD continuum using the NIA-AA AT(N) biomarker framework and the Braak neuropathological staging system.  It also seeks to develop predictive models and globally contextualised results using GBD data.
